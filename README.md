# ego004

I build production AI systems — and try to make them cheap and correct.

Most of my day-to-day work lives in private repos: an LLM document-extraction engine that turns 40+ page tender bundles into structured, source-grounded requirement data (verbatim-quote grounding, amendment-chain reconciliation, ~10x inference cost reduction), and before that, agent pipelines for a learning platform and a self-correcting agentic ETL engine at a US startup. Happy to walk through the architecture of any of it.

**Public projects**

- [aryaFaceRecognition](https://github.com/ego004/aryaFaceRecognition) — real-time multi-camera face recognition: FaceNet 512-d embeddings in ChromaDB (HNSW, cosine) with a custom IOU-based tracker.
- [unvelit_moderation](https://github.com/ego004/unvelit_moderation) — content-moderation API for an anonymous forum; perceptual-hash dedup done in plain MySQL.
- [skillswap](https://github.com/ego004/skillswap) — skill matching with Sentence-BERT + FAISS.

**Stack** — Python, C/C++, TypeScript, SQL · PyTorch, LangChain/LangGraph, RAG, FAISS, ChromaDB · FastAPI, Flask, PostgreSQL, MySQL, Docker
